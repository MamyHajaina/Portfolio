Project information

  • Category: Application web
  • Établissement: Picolino
  • Technologies utilisées: Angular · Spring Boot · Three.js · Python · Blender · MySQL · Docker
Digitalisation et automatisation du processus de commande et de livraison de modèles 3D

Ce projet a consisté à transformer un processus manuel et fragmenté en une plateforme web unifiée. L'application permet aux clients, administrateurs et modélisateurs de piloter l'ensemble du cycle de vie des modèles 3D, depuis la gestion des commandes jusqu'à la génération automatique des rendus.

  • Front-end Angular et expérience utilisateur :
    • Développement de l'interface utilisateur avec Angular pour offrir un espace de travail fluide, structuré et sécurisé aux clients et aux administrateurs.
    • Implémentation des écrans de création, suivi et gestion des commandes, ainsi que des modules d'administration des modèles 3D et des textures.
    • Intégration d'un viewer 3D interactif avec Three.js dans l'application Angular pour visualiser et manipuler les modèles directement dans le navigateur.
  • Back-end et automatisation des rendus :
    • Conception d'une API REST Spring Boot pour gérer les commandes, les modèles 3D, les utilisateurs et la communication entre les différents services.
    • Génération automatique de packshots à partir des modèles 3D via Python + Blender.
    • Pipeline de rendu optimisé pour réduire le temps de traitement et assurer la qualité des images.
    • Communication entre les services via une API REST intégrant Angular ↔ Spring Boot ↔ Python.
  • Fonctionnalités avancées :
    • Tableau de bord administrateur développé avec Angular pour la gestion des utilisateurs, des paiements et des statistiques.
    • Authentification sécurisée et gestion des rôles (client, admin, modélisateur).
    • Déploiement sur infrastructure conteneurisée avec Docker et base de données MySQL.
